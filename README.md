# practice-sns

Java와 Spring Boot 학습을 위해 만든 SNS 프로젝트입니다.
RESTful API(`/api/**`)와 Thymeleaf 서버사이드 렌더링을 함께 사용합니다.

## 🛠 기술 스택

- **Java 21**, **Spring Boot 3.4.5**, Gradle
- Spring Data JPA + **MySQL**
- Spring Security + **JWT**(jjwt 0.12.5) — httpOnly 쿠키 기반 인증
- Thymeleaf, Lombok
- 테스트: **JUnit 5**, Mockito, MockMvc, **H2**(인메모리)

## 📌 주요 기능

### 👤 사용자

#### 🟢 회원가입 ✅
- `id`, `password`를 전달받아 처리
- `id` 조건
  - 4~10자
  - 영어 소문자, 숫자, `.`, `_` 사용 가능
  - 숫자로만 구성될 수 없음
  - `.`, `_`가 연속되거나 맨 앞·뒤에 올 수 없음
- `password` 조건
  - 8~15자
  - 대문자, 소문자, 숫자, 특수문자 **모두** 포함
- `id` 중복 확인 후 DB에 저장
- 검증 실패 시 `GlobalExceptionHandler`가 400과 안내 문구를 반환

#### 🔐 로그인 / 로그아웃 ✅
- `id`, `password` 검증 후 JWT 토큰 발급
- 토큰은 **httpOnly 쿠키(`JWT_TOKEN`)** 로 내려가며, 이후 모든 요청에 자동으로 실려 인증에 사용됨
- 로그아웃 시 쿠키를 만료시켜 로그아웃 처리

#### 🧑 프로필 기능 ✅
- 프로필 이미지, 닉네임 등 기본 정보 확인
- 닉네임 수정 가능 (본인 프로필에서만 수정 버튼 노출)
  - 닉네임 변경 시 JWT를 새로 발급해 쿠키를 갱신
- 프로필 하단에 해당 사용자가 작성한 게시물 피드 표시
- 프로필 URL은 닉네임이 아닌 **userId** 기준 (`/profile/{userId}`)

#### 🤝 팔로우 ✅
- 프로필에서 팔로우 / 언팔로우 (토글)
- 팔로워 · 팔로잉 수 표시, 숫자를 누르면 목록 모달로 확인
- 피드 상단 **전체 / 팔로잉** 탭 — 팔로잉 탭은 내가 팔로우한 사용자의 게시물만 표시
- 자기 자신, 정지된 사용자는 팔로우할 수 없음
- `(follower, following)` 복합 유니크 제약으로 중복 팔로우를 DB에서 차단

#### ❌ 회원탈퇴 기능 ✅
- 로그인한 사용자가 자신의 계정을 삭제
- 탈퇴 시 관련 데이터 **모두 삭제** (게시물 / 댓글 / 좋아요 / 팔로우 / 알림)
- 탈퇴 후 쿠키 만료로 자동 로그아웃 처리

---

### 📝 게시물 / 💬 댓글 / ❤️ 좋아요

#### 게시물 ✅
- **제목 없이 내용과 사진**으로 작성 (인스타그램·X 스타일)
- 사진은 필수이며 `MultipartFile`로 업로드, MIME 타입 검증으로 이미지 파일만 허용
- 작성 / 조회 / 수정 / 삭제
- 수정은 작성자 본인만, 삭제는 작성자 본인 또는 관리자
- 전체 게시물 피드 조회, 피드에서 게시물 클릭 시 모달로 상세 보기
- 모달에서 작성자 닉네임 클릭 시 해당 작성자 프로필로 이동

#### 댓글 ✅
- 게시물에 댓글 추가
- 수정은 작성자 본인만, 삭제는 작성자 본인 또는 관리자
- 게시물의 전체 댓글 조회

#### 좋아요 ✅
- 게시물 및 댓글에 좋아요 추가 / 취소

#### 🏷 해시태그 ✅
- 게시물 본문의 `#태그`를 정규식으로 추출해 저장 (한글 · 영문 · 숫자 · `_`)
- 대소문자를 구분하지 않으며(`#Daily` = `#daily`), 한 게시물당 최대 30개
- 본문의 해시태그는 링크로 표시되고, 누르면 해당 태그의 게시물 목록으로 이동
- 게시물 수정 시 기존 연결을 지우고 본문 기준으로 다시 연결

---

### 🔔 알림 ✅

- 팔로우 / 게시물 좋아요 / 댓글이 발생하면 대상 사용자에게 알림 생성
- 헤더의 종 아이콘에 읽지 않은 알림 수를 표시하고, 누르면 목록을 드롭다운으로 표시
- 댓글 알림은 어떤 댓글인지 내용 미리보기를 함께 표시
- 알림을 누르면 해당 게시물 상세 또는 프로필로 이동
- **알림 생성 정책**
  - 본인의 행동에는 알림을 만들지 않음
  - 팔로우 · 좋아요는 껐다 켜는 동작이므로 중복 알림을 만들지 않고, 취소 시 기존 알림을 삭제
  - 댓글은 여러 번 달 수 있으므로 매번 새로 생성

### 🔍 검색 ✅

- 헤더 검색창에 입력하면 드롭다운으로 즉시 결과 표시 (250ms 디바운스)
- **사용자**와 **해시태그**를 한 번에 검색
- 해시태그는 게시물 수를 함께 표시 (`GROUP BY` 집계로 단일 쿼리 조회)
- 검색어 앞의 `#`은 무시 (`#일상`, `일상` 모두 동작)
- 정지된 사용자는 결과에서 제외

---

### 🛠️ 관리자 기능

#### 게시물 / 댓글 삭제 ✅
- 관리자는 모든 게시물·댓글을 삭제할 수 있음

#### 사용자 정지 ✅
- **프로필 페이지에서 닉네임 클릭** → 정지 기간 선택 후 정지
  - 정지 기간: 1일, 3일, 7일, 30일, 90일, 영구 정지
- 정지된 사용자의 콘텐츠는 **삭제하지 않고 가림(마스킹)** 처리
  - 피드: 정지 사용자의 게시물은 목록에서 제외
  - 게시물 상세 / 댓글: "이용이 정지된 유저입니다"로 표시하여 원문 노출 방지
  - 프로필: 피드 영역에 정지 안내 문구 표시
- 정지 기간이 지나면 **자동으로 원래대로 복구** (별도 해제 작업 불필요)
- 정지된 계정은 로그인 시 정지 안내와 함께 차단

## ⚡ 페이징과 쿼리 최적화

- 피드는 `Slice` 기반 페이징으로 조회하고, 화면에서는 **무한 스크롤**로 이어서 불러옴
- 초기에는 게시물마다 좋아요 수 · 좋아요 여부 · 댓글 수를 각각 조회해 **게시물 18건에 쿼리가 59번** 나갔음
- 게시물 id를 모아 종류별로 한 번씩만 조회하도록 바꾸고(`GROUP BY` 집계 + `IN` 조회), 작성자는 `JOIN FETCH`로 함께 조회하여 **쿼리 6번**으로 감소
- 정지 사용자 필터링도 자바 코드가 아닌 쿼리 조건으로 옮겨, 페이징 개수가 어긋나지 않도록 수정

## 🧪 테스트

```bash
./gradlew test
```

- 총 **35개** (서비스 단위 테스트 15 / API 테스트 19 / 컨텍스트 로드 1)
- 서비스는 **Mockito**로, API는 **MockMvc**로 검증
- 테스트는 `src/test/resources/application.properties`의 **H2 인메모리 DB**를 사용하므로 실서비스 DB(`sns_db`)에 영향을 주지 않음
  - H2에서는 `user`가 예약어라 JDBC URL에 `NON_KEYWORDS=USER`를 지정

## 🔑 인증 방식

- 로그인 성공 시 서버가 JWT를 발급해 **httpOnly 쿠키**로 설정
- 서버의 `JwtAuthFilter`와 각 API가 쿠키의 토큰을 읽어 인증 처리
- 클라이언트(브라우저)는 토큰을 직접 보관하지 않으며, 로그인이 필요한 페이지(예: 게시글 작성)는 서버에서 접근을 제어
- 인증 실패는 `AuthenticationEntryPoint`에서 **비로그인(401)** 과 **계정 정지(403)** 로 구분해 응답

## ▶️ 실행 방법

1. MySQL에 데이터베이스 생성
   ```sql
   CREATE DATABASE sns_db CHARACTER SET utf8mb4;
   ```

2. `src/main/resources/application.properties` 작성 (git에 포함되지 않음)
   ```properties
   spring.application.name=sns

   spring.datasource.url=jdbc:mysql://localhost:3306/sns_db?serverTimezone=UTC&characterEncoding=UTF-8
   spring.datasource.username=<사용자명>
   spring.datasource.password=<비밀번호>
   spring.datasource.driver-class-name=com.mysql.cj.jdbc.Driver

   spring.jpa.hibernate.ddl-auto=update
   spring.jpa.show-sql=true
   spring.thymeleaf.cache=false

   # HS256 서명용 시크릿 (최소 32바이트 이상)
   jwt.secret=<시크릿_키>

   # 업로드한 이미지가 저장될 경로
   file.upload-dir=<업로드_디렉터리_경로>
   ```

3. 애플리케이션 실행
   ```bash
   ./gradlew bootRun
   ```
   실행 후 `http://localhost:8080` 접속
